# SquarePlate

把照片**原样 1:1 放进正方形画布**，并按相机厂商风格自动生成**机型信息水印**。纯本地处理，不上传任何服务器。

适合发朋友圈 / 小红书 / Instagram 前给照片"装裱"—— 照片不缩放、不裁切，画布由原图向外扩充，配合哈苏、徕卡风格的厂商字标与拍摄参数行。

| 版本      | 文件                                 | 适合                          |
| ------- | ---------------------------------- | --------------------------- |
| **网页版** | [`web/index.html`](web/index.html) | 图形界面，拖拽即用，零依赖零安装。**推荐先试这个** |
| 命令行版    | [`squareplate.py`](squareplate.py) | 批量处理、脚本自动化、需保留 EXIF 时       |

## 效果说明

默认输出即"经典排版"：

- **照片区**：照片 1:1 原样绘制，一个像素都不缩放、不重采样
- **顶部**：厂商字标（斜体衬线、宽字距，如 `HASSELBLAD`、`LEICA`）
- **底部**：机型名 + 拍摄参数行（`FL 65mm · Aperture f/2.6 · Shutter 1/387 · ISO 50`，灰标签 + 主色值）
- **所有文字水平居中**，颜色按所处背景明暗自动黑/白，永远不会隐进同色背景

拍摄参数自动从照片 **EXIF** 读取；手机联名机型（OPPO·哈苏、vivo·蔡司、小米·徕卡等）的机型名来自 EXIF，字标手动选光学品牌，两者独立。

## 快速开始（网页版）

1. 下载 `web/index.html`，双击用浏览器打开（也可部署到 GitHub Pages / Vercel）
2. 把照片拖进去（或点选、或 Ctrl+V 粘贴），支持多选
3. 右侧调参数，中间实时预览
4. 「下载当前图」或「全部下载 (ZIP)」

- 网页版用 Canvas 在本机处理，**照片一个字节都不上传**，断网也能用
- 浏览器无法搬运原始 EXIF，**导出图片不含任何拍摄信息**（无机型、无 GPS）—— 公开发图更安全

## 快速开始（命令行版）

```bash
pip install Pillow

# 默认即是经典排版：照片 1:1 保真 + 字标 + 机型参数行（信息水印默认启用）
python squareplate.py photos/ -o out/

# 手机联名机型：机型来自 EXIF，字标手动选光学品牌
python squareplate.py photos/ -o out/ --brand hasselblad

# 画布占比 130%（照片仍 1:1，四周留白更多）
python squareplate.py photos/ -o out/ --zoom 130

# 信息区加深色底条（贴合照片下边缘，文字自动变白）+ 中文标签
python squareplate.py photos/ -o out/ --info-bar --label-lang zh

# 只要文字水印，不要相机信息
python squareplate.py photos/ -o out/ --no-info --text "@my_ig" --anchor br
```

直接运行 `python squareplate.py`（不带参数）会打印上手示例。

## 功能

### 画布

- 照片**始终 1:1 原样输出**，画布边长 = 照片最长边 × 占比（100%~220%），向外扩充
- 边框风格：纯色 / 毛玻璃（取原图放大模糊）/ 投影（CLI 版 `--border blur|shadow`）
- 质量档位（JPG）：极致 100 / 高 95 / 标准 90 / 分享 82 / 轻量 75，网页版面板实时显示**真实编码后**的文件大小

### 相机信息水印（默认启用）

- 内置 **25 家厂商的文字字标**（相机 17 + 手机 8）：哈苏 HASSELBLAD、徕卡 LEICA、索尼 SONY、尼康 NIKON、佳能 Canon、富士 FUJIFILM、松下 LUMIX、奥林巴斯/OM、理光 RICOH、苹果 iPhone、华为 HUAWEI、小米 Xiaomi、三星 SAMSUNG、大疆 DJI、GoPro、蔡司 ZEISS、适马 SIGMA、腾龙 TAMRON、OPPO、vivo、一加、真我、努比亚、魅族、Nothing
- 识别规则：读 EXIF 的 `Make` + `Model` 做子串匹配；没有 EXIF 的图（截图、社交软件转发）对应项自动跳过，可手动指定厂商
- 每一项独立开关：字标 / 机型 / 焦距 / 光圈 / 快门 / ISO / 等效焦距 / 日期
- 机型行可自定义文字（`--model-text`）；参数行标签可选英文 / 中文 / 无标签
- 可选**信息底条**：纯色条顶边贴合照片下边缘，文字颜色按条色自动适配
- 字号缩放（50%~220%）与字重（细/常规/中等/粗）可调

> ⚠️ **关于商标**：内置的是厂商的**文字字标**，不是官方商标图形。商标图形属于各厂商的注册资产，本项目不内置、不分发。如需标准 logo，请通过「图片水印」上传你自有的授权素材。

### 文字 / 图片水印

- 文字水印：字体（含自定义上传 ttf）、字号、颜色（默认 `auto` 按底色黑/白）、透明度、描边、投影、九宫格九位、斜向 45° 平铺
- 图片水印：logo 占比 / 透明度 / 位置 / 边距

### 两版差异

|             | 网页版           | 命令行版                 |
| ----------- | ------------- | -------------------- |
| 照片处理        | Canvas，本机     | Pillow，多进程           |
| EXIF        | 导出不含（浏览器限制）   | 默认保留，`--no-meta` 可剥离 |
| 批量          | 多图队列 + ZIP 打包 | 递归扫描 + 并发            |
| 实时预览 / 底色切换 | ✅             | —                    |

## 命令行参数

### 输入输出

| 参数                | 默认          | 说明                        |
| ----------------- | ----------- | ------------------------- |
| `inputs`          | 必填          | 图片文件或目录，可多个               |
| `-o, --output`    | `./squared` | 输出目录                      |
| `-r, --recursive` | 关           | 递归扫描子目录（同名文件自动加前缀，不会互相覆盖） |
| `--overwrite`     | 关           | 覆盖已存在的输出                  |

### 画布与画质

| 参数                | 默认     | 说明                                                 |
| ----------------- | ------ | -------------------------------------------------- |
| `--zoom`          | `100`  | 画布边长相对照片最长边的倍率 %（100~220），照片 1:1 不缩放               |
| `--quality-level` | `high` | JPG 质量档位：`max` / `high` / `std` / `share` / `lite` |

### 边框与水印

| 参数                                                                       | 默认      | 说明                                        |
| ------------------------------------------------------------------------ | ------- | ----------------------------------------- |
| `--border`                                                               | `solid` | `solid` 纯色 / `blur` 毛玻璃 / `shadow` 投影     |
| `--border-color`                                                         | 白       | `white` `black` `gray` `#RRGGBB` `RRGGBB` |
| `--blur`                                                                 | `30`    | 毛玻璃模糊半径                                   |
| `--text` / `--wcolor` / `--opacity` / `--stroke` / `--anchor` / `--tile` | —       | 文字水印（`--wcolor auto` 按底色自动黑/白）            |
| `--logo` / `--logo-ratio` / `--logo-anchor`                              | —       | 图片水印                                      |

### 相机信息水印

| 参数                                                                                           | 默认            | 说明                                    |
| -------------------------------------------------------------------------------------------- | ------------- | ------------------------------------- |
| `--no-info`                                                                                  | —             | 关闭相机信息水印（默认启用）                        |
| `--brand`                                                                                    | `auto`        | `auto` 或厂商 id（如 `hasselblad` `leica`） |
| `--info-bar` / `--info-bar-color`                                                            | 关 / 近黑        | 信息区加纯色底条 / 指定条色                       |
| `--info-scale` / `--info-weight`                                                             | `100` / `500` | 信息文字字号缩放 % / 字重（300细~700粗）            |
| `--model-text`                                                                               | 空             | 自定义机型行文字，留空用 EXIF                     |
| `--label-lang`                                                                               | `en`          | 参数行标签：`en` / `zh` / `none`            |
| `--no-model` `--no-brand` `--no-focal` `--no-aperture` `--no-shutter` `--no-iso` `--no-date` | —             | 逐项关闭（默认显示）                            |
| `--eq35`                                                                                     | 关             | 显示 35mm 等效焦距                          |
| `--lens`                                                                                     | 关             | 显示镜头名                                 |

### 输出格式

| 参数              | 默认     | 说明                           |
| --------------- | ------ | ---------------------------- |
| `-f, --format`  | `keep` | `keep` 沿用原格式 / `jpg` / `png` |
| `-q, --quality` | `95`   | JPEG 质量（未用档位时）               |
| `--no-meta`     | 关      | 丢弃 EXIF / ICC（公开发图建议开启）      |
| `-j, --jobs`    | 自动     | 并发进程数                        |

> 历史遗留参数（`--size`、`--canvas-mode`、`--offx` 等）仍可传入但会被忽略，不报错。

## 注意事项

- **EXIF 方向修正**：手机竖拍照片（Orientation=6）会先转正再入画，方向不会错乱
- **隐私**：命令行版默认保留 EXIF（含机型与 GPS），公开发图建议加 `--no-meta`；网页版导出不含任何 EXIF
- **EXIF 识别率**：截图、社交软件转发过的图通常已被剥离 EXIF，自动识别会失败，界面与 CLI 都会提示，可手动指定厂商
- **JPEG 压缩**：CLI 版已设 `subsampling=0`（4:4:4），避免细字水印出现彩色边缘
- **超大图**：已解除 Pillow 的 DecompressionBomb 限制；处理不可信来源的图片时请留意
